# LAB-012 边界

main（验收/日志） -> timer_probe（单调用者硬件诊断） -> LL/CMSIS；初始配置由 CubeMX2 HAL 生成。应用不修改 vendor 或 generated 文件。

HAL 完成初始化后由探针独占 TIM1，读取计数方向、轮询更新事件，并执行软件 break / 显式 rearm。计数探测每次约 100 ms，门控反馈各最多等待 5 ms，保持关闭观察 20 ms。探针返回结构化结果，不在计数窗口内发送串口。SysTick 是时间窗口依据。

这不是生产用 PWM 服务。引入生产接口前，应规定外设所有权、故障状态机、引脚静态状态和外部故障恢复条件；目前没有真实功率负载与外部安全链。
